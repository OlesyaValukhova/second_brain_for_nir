# Second brain for NIR — детская мобильность и дополнительное образование

Исследовательская база для проекта о пространственной доступности организованных внешкольных занятий детей в Санкт-Петербурге, возможности самостоятельных поездок и транспортной нагрузке на семьи.

## Структура

- `literature/` — карточки проверенных публикаций (DOI, вопрос, данные, методы, результаты, ограничения, применение к проекту).
- `synthesis/` — тематические сопоставления и исследовательские пробелы.
- `research-log/` — журнал этапов поиска, решений и открытых вопросов.

## Правила ведения

1. Разделять: (а) утверждения авторов, (б) наши интерпретации, (в) гипотезы, требующие проверки.
2. Не выдавать потенциальную доступность по графу за наблюдаемое поведение, независимую мобильность или фактические поездки родителей.
3. Проверять библиографию и давать DOI/ссылку; указывать, какие разделы проверены (аннотация или полный текст).
4. Не объявлять отсутствие исследований или научную новизну без систематической проверки.
5. Сохранять неопределённость при неполных геоданных, негеокодированных группах и различиях между карточками программ и фактическими местами занятий.
