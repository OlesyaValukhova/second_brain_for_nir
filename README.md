## Рабочая база Obsidian

Единственная рабочая база заметок находится в [`vault/`](vault/). Эту папку нужно открывать в Obsidian на каждом устройстве.

Папка [`research/`](research/) пока сохранена как источник для сверки и переноса уникальных материалов. Не редактируйте в ней заметки как во второй рабочей версии: это снова создаст расхождение.

Перед работой на новом устройстве: получите изменения из GitHub (`pull`). После содержательной сессии: сохраните изменения в GitHub (`commit` и `push`).
