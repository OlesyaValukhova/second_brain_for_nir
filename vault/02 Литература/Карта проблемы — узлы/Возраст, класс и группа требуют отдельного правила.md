# Возраст, класс и группа требуют отдельного правила

Возраст программы не всегда совпадает с возрастом доступной в расписании группы: у курса робототехники диапазон 4–7 лет разделён на группы 4–6 и 6–7. Общий допуск не определяет, есть ли подходящее время для ребёнка.

Три строки ИТМО содержат школьный класс вместо возраста. Класс нельзя однозначно перевести в годы без заранее заданного правила или уточнения у организатора. Две временные группы одного курса также нельзя автоматически считать двумя разными программами.

## Что следует для расчёта

Перед подсчётом нужен явный фильтр: числовой возраст либо отдельно обоснованное сопоставление классу, а при наличии расписания — возрастной допуск конкретной группы. Это правило определяет состав подходящего предложения, а не поведение семьи.
