# Журнал сбоев: общегородский пешеходный граф (11.11.2026)

Для B1 был подготовлен вход из 30 611 жилых точек Urban API и штатный pipeline `prepare_library_walk_graph.py` через BlocksNet/IduEdu. Попытки скачать общегородскую сеть OSM завершились без графа:

| Попытка | Endpoint | Результат |
|---|---|---|
| r3 | `overpass-api.de` | HTTP 502: очередь занята; сохранено 134.63 MiB частичного кэша |
| r4 | `overpass.private.coffee` | `ReadTimeout` через 60 секунд |
| r5 | `overpass.kumi.systems` | запрос завис без роста кэша и без CPU; остановлен вручную |

Это состояние внешних OSM-серверов, а не доказательство отсутствия пешеходной сети. Не заменять B1 прямыми расстояниями или островной картой. Пока не получен целый валидный городской граф, допустимый результат — подготовленный набор входных слоёв, воспроизводимый код и уже рассчитанный островной пилот.
