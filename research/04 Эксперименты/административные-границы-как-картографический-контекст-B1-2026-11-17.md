# Административные границы как картографический контекст для B1

Дата: 17.11.2026

Статус: методическое пояснение к оформлению карт; новые расчёты и исследовательские выводы не добавляются.

## Зачем добавляется слой

Квартальные карты BlocksNet трудно соотносить с географией Санкт-Петербурга без внешних ориентиров. Для повышения читаемости на тематические карты B1 можно наложить тонкие линии административных границ 18 районов города.

Это только картографический контекст. Административные районы:
- не заменяют существующие кварталы BlocksNet;
- не используются для расчёта доступности, парных разниц или знаменателей;
- не становятся новой единицей агрегации;
- не меняют выводы B1.

## Источник и обработка

Для контекстного слоя используются отношения OpenStreetMap с тегами `boundary=administrative`, `admin_level=5`. Документация OpenStreetMap по районам Санкт-Петербурга перечисляет 18 районов и указывает, что сведения для разметки границ берутся с официального сайта Правительства Санкт-Петербурга.

Источник: [OpenStreetMap Wiki — районы Санкт-Петербурга](https://wiki.openstreetmap.org/wiki/RU:%D0%A1%D0%B0%D0%BD%D0%BA%D1%82-%D0%9F%D0%B5%D1%82%D0%B5%D1%80%D0%B1%D1%83%D1%80%D0%B3/%D0%A0%D0%B0%D0%B9%D0%BE%D0%BD%D1%8B).

Официальная система открытых данных: [Открытые данные Санкт-Петербурга](https://www.gov.spb.ru/gov/otrasl/c_information/napravlenie-deyatelnosti-komiteta/otkrytye-dannye/).

В картографическом процессе:
1. Загружаются 18 отношений OSM.
2. Проверяются ID, русские названия, `admin_level=5`, `boundary=administrative`, полигональная геометрия и валидность.
3. Геометрия переводится в EPSG:32636 для совмещения с BlocksNet.
4. На тематические карты накладываются только тонкие контуры.
5. На карте указываются источник и атрибуция © OpenStreetMap contributors, ODbL 1.0.

## Ограничения

- OSM — внешний картографический источник; использование границ не означает отдельной юридической проверки их актуальности.
- В BlocksNet по-прежнему нет административных атрибутов; районный слой не присоединяется к кварталам.
- В B1 не появляются районные средние или новые районные выводы.
- Показатель N остаётся количеством уникальных опубликованных координат Navigator с возрастно-допустимыми карточками, а не количеством программ, групп, мест или участников.

## Итоговая проверка карт v42

17.11.2026 слой из 18 районных отношений OpenStreetMap был загружен и проверен в основном репозитории. Все геометрии валидны, MultiPolygon, EPSG:32636. Их объединение пересекает 99,9268% площади объединения 3 330 полигонов BlocksNet. Районные границы добавлены на пять карт B1 и двухпанельную карту программирование / ИЗО; они остаются только ориентиром и не используются для агрегации.

Для конвертации исключены 111 вложенных relation-ссылок с ролью `subarea`; исходный Overpass JSON сохранён, внешние way-геометрии использованы для границ родительских районов.
