# Открытые вопросы и проверки

Обновлено: 09.11.2026. Прежние записи сохранены в [[История идеи]].

| Вопрос | Текущий статус и действие |
|---|---|
| Универсальные международные тезисы | Не подтверждены; различать страну/выборку/цель, автомобильную долю и минуты |
| Время родителей и оплачиваемая работа | Контекстные основания есть; полного доказательства причинного масштаба нет |
| Пробки и автомобильный спрос | Нельзя приравнивать; наш метод вклад в заторы не оценивает |
| Научная новизна | Возрастные и программные аналоги найдены; проверять вклад адаптации базовыми сравнениями |
| Петербургская городская проблема | Конкретный дефицит/неравенство ещё не установлены пространственным пилотом |
| Данные | Нет полного подтверждённого слоя мест и актуальных возрастных условий; районный фильтр не вся возможность жителей |
| Неизвестные даты/возраст | Сценарии, не скрытое включение; проверять верхнюю границу шкалы возраста |
| Сеть | Не подготовлена реальная матрица; синтетика не географическое свидетельство |
| Нормативы | Не все официальные консолидированные файлы получены; пешая база не проверяет пешеходно-транспортное требование |
| UML предметного процесса | Реконструкция, не подтверждённый полный as-is; не фантазировать регламент |
| Первая и вторая редакции | Старый PDF существует, интеграция новых материалов не завершена |
| Manz 2015 и старые числа Waygood | Исходники сохранены; непроверенные выписки не цитировать как установленный результат |
| Q1–Q2 для новых контекстных источников | У ряда работ пока не проверены система/год/категория; не объявлять включёнными автоматически |
